# 誤解之神

> 你是神，但人類永遠不懂你。

一款看著人類文明演化的網頁上帝遊戲。人類會自己生存、遷徙、發展，你只能花信仰施展奇蹟從旁幫忙。但每個奇蹟都有副作用，人類也總會用他們自己的方式誤解你。

- 開局像《缺氧》挑複製人一樣抽三位始祖，天賦、缺陷、興趣會變成部族的血統
- 研究樹有六條路線：農耕、航海、工藝、戰爭、自然、神秘學，點不完，要選方向
- 從原始時代走到未來時代，9 種結局（含隱藏結局），路線會影響結局
- 17 種地形、9 種動物（含海洋生物與海怪）、13 種奇特事件
- 瘟疫、戰爭、天災、污染、核戰……袖手旁觀的話，文明隨時可能滅亡
- 人類會因為你的作為產生各種神話，神話又會改變他們的發展
- 滅亡或結局之後，遺跡會埋進下一個世界
- 關掉遊戲後世界仍會慢慢運轉，危機發生時會停下來等你

## 怎麼玩

純前端，不需要安裝。直接用瀏覽器開啟 `index.html`，或部署到 GitHub Pages。進度存在瀏覽器的 localStorage。

## 專案結構

| 檔案 | 內容 |
|---|---|
| `js/data.js` | 所有遊戲內容：地形、動物、始祖特質、研究樹、奇蹟、神話、事件、奇特事件、危機、結局。**擴充內容只要改這個檔** |
| `js/sim.js` | 模擬核心（不碰 DOM） |
| `js/render.js` | 地圖繪製 |
| `js/ui.js` | 介面、主迴圈、存檔、離線進度 |
| `tools/balance.js` | 平衡測試：`node tools/balance.js 40 active｜random｜passive [路線]` |
